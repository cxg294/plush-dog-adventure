# 产品决定

- 目标是一个可直接游玩的原创四关平台游戏，而非复刻任天堂的原始素材。
- 主角选用本机当前选中的 Codex 宠物 `custom:plush-dog`；保留其动作图集原文件，并在浏览器内清理图集背景色。
- 使用 Canvas 绘制原创像素场景和敌人；浏览器 Web Audio 合成短音效，避免网络或打包依赖。
- 保留平台游戏熟悉的关卡节奏：安全起点、早期问号块、管道、逐渐增密的敌人、两个坑、终点台阶与旗杆。
- 桌面键盘和触屏均可操作；支持暂停、静音与重新开始。

## 第二轮升级

- 地表与地下岩洞使用独立的地形、金币、敌人、道具和背景；切换空间时保留已经探索的状态。
- 地表第 54 格的爪印管道为秘密入口。站在管道顶按 `↓`/`S` 可进入岩洞；岩洞两端的管道分别返回原处与地表后段。
- 新增速度靴（二段跳）、星星（限时无敌）、磁铁（吸取附近金币）和爱心（额外生命）；骨头护盾继续保留。
- 怪物分为蘑菇怪、双层甲壳虫、飞行蝙蝠和岩洞软泥；它们具有不同的运动与受击规则。
- 增加连踩得分、弹簧、存档点和岩洞奖励路线，同时保持 1-1 主线可不走秘密管道完成。
- 画面增加多层视差、光照、地表细节、岩洞晶体与局部发光、道具与怪物动画、过场和更清晰的状态提示。

## 第三轮升级

- 增加 1-2 落日果园、1-3 云端花园和 1-4 月夜城堡；首页可直接选关，正常游玩则顺序通关。
- 使用与柴犬宠物图集一致的像素颗粒和配色生成新背景，并在 Canvas 中补齐关卡前景。
- 狗狗动作增加方向镜像、落地压缩和起跳拉伸；护盾、靴子、星星、磁铁、星火铃铛、旋风爪套有独立的身上效果。
- 星火铃铛提供远程弹丸，旋风爪套提供近身挥击；1-4 的守卫具有三段生命，击败后终点解除封锁。
- 新增四关切换、装备继承与关卡存档点，保留原有的隐藏岩洞往返。
