# 团子狗大冒险 · Plush Quest

一只毛绒小狗的四关横版冒险。探索草原、果园、云海和月夜城堡，用双跳、蹬墙、冲刺、挥爪与声波突破障碍，寻找星晶和秘密岩洞，挑战两位三阶段首领。

**在线试玩：<https://cxg294.github.io/plush-dog-adventure/>**

游戏使用 960 × 540 Canvas，支持桌面键盘与手机多点触控。角色来自团子狗动作图集；五个场景的背景素材保存在 `assets/`，敌人、装备、机关和特效由 Canvas 绘制，音乐与音效由 Web Audio 合成。运行时无第三方依赖，无须登录。

## 本地运行与测试

需要 Python 3；运行测试另需 Node.js。在项目根目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://localhost:4173/>。静态页面和素材均由本地服务器提供，不需要安装 npm 包或执行构建。点击“开始冒险”从当前选中关卡出发，也可在首页选择 1-1 至 1-4。

```sh
node tests/smoke.cjs
node tests/gameplay.cjs
node tests/routes.cjs
node tests/boss-routes.cjs
```

测试覆盖关卡切换、碰撞、道具、隐藏管道，以及双跳、墙跳、冲刺、下砸、战斗、体力、复活、存档和首领行为。测试使用固定步长模拟，不依赖浏览器或网络。路线验证只通过真实输入从起点抵达旗帜或首领场地；首领战模拟通过实际移动、跳跃、攻击和声波完成三个阶段并抵达出口。发布前执行以上四组检查。

## 桌面操作

| 操作 | 按键 | 用法 |
| --- | --- | --- |
| 移动 | A / D 或 ← / → | 空中也能调整方向 |
| 跳跃 / 双跳 | 空格、W 或 ↑ | 起跳后松开并再按一次即可双跳；短按控制跳跃高度 |
| 墙滑 / 墙跳 | 面向墙壁移动，再按跳跃 | 在墙边减缓下落，蹬墙跳向另一侧 |
| 加速跑 | Shift 或 X | 按住加速 |
| 挥爪 / 装备攻击 | J 或 Z | 未装备武器时使用基础挥爪；连续攻击形成三段连招 |
| 冲刺 | K 或 C | 沿面朝方向冲刺，可短暂避开伤害；空中一次，落地恢复 |
| 汪汪声波 | L 或 V | 震晕怪物、反弹飞弹、解除爪印宝箱封印 |
| 蹲下 / 下砸 / 管道 | S 或 ↓ | 地面蹲下，空中下砸；站在爪印管道顶按向下进入 |
| 暂停 / 继续 | P 或 Esc | 暂停时保存当前冒险 |
| 音频 | M | 开关全部音频；背景音乐可用顶部音乐按钮独立开关 |
| 重试本关 | R | 重新挑战当前关卡 |
| 全屏 | F | 也可使用顶部全屏按钮 |
| 开始 / 确认 | Enter | 开始冒险或确认当前菜单操作 |

顶部“？”提供随时可查的操作手册；暂停或结算菜单可返回旅程首页，保留最近营地的继续存档。首次点击开始后，浏览器会启用游戏音频。

## 触屏操作

屏幕下方有 **7 个按钮**：向左、向下、向右、声波、攻击、冲刺、双跳。可同时按住方向与动作键；双跳需要松开跳跃键后再次按下，向下键会根据地面、空中或管道位置执行相应动作。页面适配手机竖屏与横屏，全屏游玩时保留触控操作。

## 移动、战斗与装备

团子默认就能双跳、墙滑、墙跳、冲刺、下砸和基础挥爪。三段挥爪连招逐步延长攻击范围；踩中敌人的头顶也能击败它们。冲刺与声波共用自动恢复的能量：冲刺消耗 25，声波消耗 35；冷却与空中次数限制需要配合跳跃使用。

| 道具 | 效果 |
| --- | --- |
| 骨头护盾 | 抵挡一次伤害，允许顶碎砖块 |
| 云步靴 | 限时获得三段跳；下降时按住跳跃可滑翔 |
| 闪光星星 | 短暂无敌，接触普通怪物即可撞飞它们 |
| 金币磁铁 | 吸取附近金币 |
| 爱心 | 恢复全部体力，并增加一次重试机会 |
| 星火铃铛 | 使用攻击键发射远程星火弹 |
| 旋风爪套 | 使用攻击键施展更大范围的近身挥爪 |
| 回旋骨头 | 使用攻击键投掷回旋骨头，往返攻击并回收 |

攻击装备与增益具有各自的持续时间，会显示在 HUD 和团子身上。声波能震晕普通怪物、反弹附近的敌方弹丸，并打开爪印宝箱获取星晶和奖励；在首领战中，还能清除地面波、反弹飞弹或打断特定蓄力。

每条生命有 **3 点体力**。受伤后有短暂无敌时间，骨头护盾优先吸收一次伤害；体力耗尽、落坑或时间耗尽会消耗一条生命。仍有生命时，从最近营地恢复满体力，保留已经收集的金币、星晶、打开的宝箱、世界探索状态及装备。营地同时提供回复与存档。

## 第一世界与首领

| 关卡 | 场景与挑战 |
| --- | --- |
| 1-1 | 草原教学、移动平台、弹簧与高处奖励路线；爪印管道通往星光岩洞，岩洞两端的管道可返回地表 |
| 1-2 | 落日果园、尖刺和吐弹怪；终点前挑战 **荆棘果王，6 HP** |
| 1-3 | 云端花园、悬空地形、移动平台和高处星晶，考验空中跳跃与冲刺的衔接 |
| 1-4 | 月夜城堡、喷火机关与尖刺；最终挑战 **月蚀石狼，12 HP** |

两位首领都有 **三个阶段**。生命降低后，会增加飞弹、连续跳跃或陨落等招式；攻击前会给出方向、范围与落点预警。躲过攻击，抓住首领核心发光时的破绽使用挥爪、下砸或装备攻击；声波反弹飞弹也是反击手段。进入首领场地后竞技场封锁，击败首领才会打开出口。

四关可连续挑战，也可在首页直接选关。过关后继承生命、得分、收集与剩余装备效果进入下一关。

## 存档与通关评价

游戏在当前浏览器的 `localStorage` 中保存营地进度、世界收集状态、装备、设置与各关最佳纪录。重新打开同一试玩地址，首页可选择“继续冒险”，回到最近营地。存档仅存在当前设备和浏览器，清除站点数据会删除纪录；如果浏览器禁用本地存储，游戏仍可游玩。

每关结算获得 S / A / B / C 评价：

- **S**：无死亡、无受伤，并收集至少 2 颗星晶。
- **A**：无死亡。
- **B**：死亡 1 次。
- **C**：死亡 2 次或以上。

最佳纪录优先保留更高评价，同评价时保留更高得分。完成城堡最终关后保留关卡纪录，并结束当前连续冒险存档。

## 项目结构

- `index.html`、`styles.css`：游戏界面、HUD、菜单与响应式触控布局。
- `game.js`：角色操作、主循环、战斗、场景绘制及音频。
- `world.js`：移动平台、机关、宝箱、星晶与奖励路线。
- `boss.js`：两位首领的阶段、预警、攻击、反弹与竞技场。
- `progress.js`：本地存档、继续冒险与关卡纪录。
- `assets/`：团子动作图集与五个场景背景。
- `tests/`：固定步长模拟与玩法回归测试。
