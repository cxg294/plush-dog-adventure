# 团子狗大冒险 · 第一世界

可离线游玩的四关横版平台游戏。主角使用当前 Codex 宠物 `custom:plush-dog` 的动作图集；五个场景的背景素材保存在 `assets/`，游戏角色、道具、敌人和特效由 Canvas 绘制，音效由 Web Audio 合成。无第三方运行依赖。

在线体验：[GitHub Pages](https://cxg294.github.io/plush-dog-adventure/)

## 运行

在本目录运行 `python3 -m http.server 4173`，打开 `http://localhost:4173`。首页可以直接选择 1-1、1-2、1-3 或 1-4；从 1-1 出发则会连续通关。1-1 的隐藏管道通往星光岩洞。

## 操作

- `A` / `D` 或 `←` / `→`：移动
- `空格` / `W` / `↑`：跳跃，按住可跳得更高
- `J` / `Z`：使用当前攻击道具
- `S` / `↓`：站在带爪印的管道顶时进入管道
- `Shift` / `X`：加速跑
- `P` / `Esc`：暂停或继续
- `M`：开关音效
- 手机和平板可用屏幕下方的移动、跑、攻击、跳跃按钮

## 道具与关卡

骨头护盾可挡一次伤害并顶碎砖块；弹跳靴提供限时二段跳；星星短暂无敌；磁铁吸取金币；爱心增加生命。新增星火铃铛，可连续发射星火弹；旋风爪套可向前挥爪攻击。装备会直接显示在狗狗身上，状态也会显示在画面上方。

1-1 是地表与隐藏岩洞，1-2 是落日果园，1-3 是云端花园，1-4 是月夜城堡。每关有独立地形、敌人、道具、存档点与终点。1-4 的城堡守卫需要击败三次才能打开终点。通关后保留生命、得分和剩余装备效果进入下一关。

运行 `node tests/smoke.cjs` 可验证移动、碰撞、道具、秘密管道、四关切换、攻击和终点。
